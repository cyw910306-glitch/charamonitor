캐릭모니터

CPU가 바쁠수록 메뉴바의 캐릭터가 더 빨리 달려요. 결제 없는 무료 오픈 소스예요.

터미널로 설치하기 직접 내려받기 GitHub 소스 코드

태닝 고양이를 잡아서 휙 던져 보세요. 빠를수록 더 신나게 달리고, 한 번 누르면 킥플립을 해요.

  • 🐾메뉴바의 캐릭터가 CPU·메모리·발열에 따라 7가지 자세로 자고, 걷고, 달려요
  • 📊클릭하면 CPU·메모리·저장 용량·배터리·네트워크를 한눈에
  • 🎨캐릭터를 골라 모습을 꾸미고, 우리 아이 사진으로 나만의 캐릭터도 만들 수 있어요
  • 🖼️사진 한 장으로 나만의 메뉴바 캐릭터 만들기. 기본은 실사라 잘라낸 사진이 그대로 움직여요 (이 맥에 ChatGPT로 로그인된 Codex가 있으면 자는 모습·뛰는 모습은 AI가 자동으로 그려요)
  • 🖱️데스크톱 친구: 커서를 따라 걷는 커서 친구, 메뉴바 아래 대롱대롱 친구, 풀밭 친구들, 바탕화면 러그, 날씨 창문, 집중 타이머
  • 🏠펫 키우기: 도트 방 꾸미기, 코인으로 사는 가구, 일일 미션, 집중 타이머 펫
  • 💬AI 비서: 이 맥 안의 AI나 내 AI(Claude · ChatGPT · Gemini, 내 키나 내 구독)로 캐릭터와 대화하고, 부탁한 일은 카드로 확인받아 실행해요
  • ✨클리너: 안 쓰는 앱·폭주 프로세스 종료, 로그·앱 캐시·개발자 캐시(npm·Homebrew)·오래된 node_modules 정리, 로그인 항목 관리, 재시동 권장 (저장 안 한 작업은 지켜요)
  • 📶버튼 하나로 인터넷 속도(Mbps) 측정
  • 🛡️보안 검사: macOS 기본 보호(악성코드 차단·방화벽·암호화)와 수상한 자동 실행 항목 점검, 되돌릴 수 있는 조치
  • 🔒혼자서는 거의 인터넷에 연결하지 않아요 (속도 재기 버튼을 누를 때 Apple 서버에, 자동 다듬기가 빈 모습을 그릴 때 이 맥의 ChatGPT(Codex)를 거쳐 OpenAI에 사진을, 켜 둔 기능(날씨 창문, 내 AI, 메일 계정)이 필요할 때 그곳에, 그리고 앱을 켤 때와 하루에 한 번 이 사이트에서 서명된 작은 버전 파일과 후원 친구 소개 목록만 받고 새 버전이 있을 때만 업데이트를 받아요). 계정, 결제, 추적, 분석 도구가 없어요
  • 💻macOS 13 이상, Apple Silicon과 Intel 맥 모두 지원
  • 🪶평소 CPU 0.3% 정도로 가볍게 돌아가요

터미널 한 줄로 설치 추천

가장 간단해요. 경고창 없이 바로 설치되고 실행까지 해 줘요.

curl -fsSL https://jelly-monitor.vercel.app/install.sh | bash
  1. ⌘ + Space로 Spotlight를 열고 터미널을 입력해 실행해요.
  2. 위 명령을 붙여넣고 Enter를 누르면 끝! 응용 프로그램 폴더에 설치되고 메뉴바에 캐릭터가 나타나요.

직접 내려받기

Finder가 편하다면 파일로 받아서 응용 프로그램 폴더로 옮겨 주세요. Finder에서는 앱 이름이 DogMonitor로 보여요.

⬇ JellyMonitor.dmg JellyMonitor.zip

처음 열 때 경고가 뜨면

macOS 15 이상

  1. 앱을 한 번 열어 봐요. 경고가 뜨면 완료를 눌러 닫아요.
  2. 시스템 설정 > 개인정보 보호 및 보안으로 가요.
  3. 아래쪽의 그래도 열기를 누르고 암호를 입력하면 돼요.

macOS 13~14

  1. 응용 프로그램 폴더에서 DogMonitor 앱을 Control 키를 누른 채 클릭해요.
  2. 메뉴에서 열기를 고르고, 한 번 더 열기를 눌러요.

그래도 안 열리면 터미널에 이 명령을 붙여넣어 주세요.

xattr -dr com.apple.quarantine /Applications/DogMonitor.app

왜 경고가 뜨나요? 개인이 만든 앱이라 Apple 공증을 받지 않아서 뜨는 안내예요. 앱은 속도 재기, 하루에 한 번 서명된 버전 파일 확인(새 버전이 있으면 업데이트 받기), 자동 다듬기(이 맥에 ChatGPT로 로그인된 Codex가 있을 때만, 설정에서 끌 수 있어요), 직접 켠 기능(날씨 창문, 내 AI, 메일 계정) 말고는 인터넷에 연결하지 않아요. 소스 코드가 공개돼 있어서 직접 확인하고 빌드할 수도 있어요.

사용법

  1. 메뉴바의 캐릭터를 클릭하면 대시보드가 열려요.
  2. 캐릭터 선택에서 캐릭터를 고르고, 꾸미기에서 고른 캐릭터에 맞게 색과 모양을 바꿔 보세요.
  3. 클리너를 누르면 꺼도 되는 앱과 지울 파일을 골라 두고, 정리하기 한 번이면 정리돼요.
  4. 설정에서 로그인 시 자동 실행을 켜 두면 맥을 켤 때마다 캐릭터가 함께 나와요.
  5. 종료한 뒤 다시 켜려면 ⌘ + Space로 Spotlight를 열고 캐릭을 검색하거나, 응용 프로그램 폴더에서 캐릭모니터를 열어요.

삭제하기

메뉴바의 캐릭터를 오른쪽 클릭해 종료한 뒤, 응용 프로그램 폴더의 캐릭모니터 앱을 휴지통으로 옮기면 돼요. 예전 버전을 터미널로 설치했다면 홈 폴더 > 응용 프로그램(~/Applications)에 있을 수도 있어요.

터미널로 한 번에 지우려면 아래 명령을 쓰세요. 두 곳 모두 찾아서 지우고 설정도 정리해 줘요.

curl -fsSL https://jelly-monitor.vercel.app/install.sh | bash -s -- --uninstall

무료 · 오픈 소스

무료 오픈 소스예요. 결제는 없어요. 가끔 오는 후원 친구(제작자 서비스 소개)는 설정에서 끌 수 있고, 꾸미기 선물 8가지는 후원 친구를 끝까지 보면 하나씩 열려요 (앱스토어판은 처음부터 다 열려 있어요).

  1. 소스 코드는 GitHub에 있어요. Xcode 명령줄 도구만 있으면 swift build 로 직접 빌드할 수 있어요.
  2. 라이선스는 PolyForm Noncommercial 1.0.0이에요. 개인적·비영리 목적이면 쓰고, 고치고, 나눌 수 있어요. 돈을 받고 팔거나 상업적으로 쓰는 건 안 돼요.
  3. 앱에 들어 있는 캐릭터는 모두 오리지널이에요. 내 사진이나 내 그림 파일로 나만의 캐릭터와 캐릭터 팩을 만들 수 있어요(팩 만드는 법은 저장소의 docs/PACKS.md). 직접 권리를 가진 이미지를 사용해 주세요.
