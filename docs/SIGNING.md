# 고정 서명 인증서 (배포하는 맥에서 한 번)

왜: ad-hoc 서명은 빌드마다 다른 앱으로 취급돼서, 업데이트할 때마다 모든 사용자의 '전체 디스크 접근' 허용이 풀린다.
고정 인증서로 서명하면 macOS 가 "번들 id + 이 인증서"로 기억해서 업데이트해도 허용이 유지된다(모든 사용자 공통).
첫 교체 업데이트 한 번만 다시 허용이 필요하다.

만들기(터미널, 배포하는 맥에서 한 번):
    bash scripts/make_signing_cert.sh

인증서와 키는 ~/Library/Application Support/JellyMonitorSeller/ 에 백업된다(이관 키트에 포함할 것).
잃어버리면 새 인증서로 바뀌어 모든 사용자가 한 번 더 허용해야 한다(업데이트 자체는 계속 된다).
Apple Developer ID 를 받으면 그쪽으로 바꾸는 게 최선(공증까지 되어 설치 경고도 사라짐).
